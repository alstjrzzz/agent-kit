# Codex 개인 전역 지침

## 작업 방식

- 작업을 시작하기 전에 현재 변경사항과 관련 파일을 확인한다.
- 사용자가 이미 수정한 내용은 요청이 없으면 보존한다.
- 구현 요청이면 계획만 제시하지 말고 검증 가능한 결과까지 만든다.
- 확인한 파일과 근거를 바탕으로 판단하고, 확인하지 못한 내용은 추정이라고 밝힌다.

## 코드 변경

- 하나의 변경은 하나의 목적만 가진다.
- 관련 없는 포맷, whitespace, import 정리와 파일 변경은 피한다.
- 함수와 변수 이름은 실제 역할과 값을 드러내야 한다.
- 죽은 코드와 미사용 import·변수는 남기지 않는다.
- 주석은 코드만으로 드러나지 않는 이유를 설명할 때만 최소한으로 작성한다.

## 보안

- 시크릿과 개인정보를 소스, 로그, 예외 메시지, 명령행 인자에 넣지 않는다.
- 자격증명과 암호화 키를 하드코딩하지 않는다.
- 삭제나 덮어쓰기는 대상과 범위를 확인한 뒤 수행한다.

## 검증과 소통

- 변경된 동작과 회귀 위험에 맞는 테스트와 검사를 실행한다.
- 실행하지 못한 검사는 이유와 미검증 범위를 결과에 적는다.
- 사용자에게는 자연스럽고 간결한 한국어로 결과와 남은 주의를 전달한다.
