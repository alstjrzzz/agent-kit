# agent-skills
Personal collection of Agent Skills (SKILL.md) for Claude Code, Codex, and other AI agents.

## What's here

Each folder in this repo is a self-contained skill: a SKILL.md file containing a short description (when to use it) and instructions (what to do). Some skills may also include supporting scripts, references, or templates.

## Skills

- **writing-style** — Tone and structure guide for personal tech blog posts: study notes, troubleshooting logs, and performance/benchmark records.

## Usage

This repo is a personal backup and reference, not an installable package. To use a skill with an agent, copy the relevant folder into that agent's personal skills directory (for example, `~/.claude/skills/` for Claude Code, or `~/.codex/skills/` for Codex).
